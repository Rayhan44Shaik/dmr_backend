# DMR Poultries ERP Rules

Trip Entry is the heart of the ERP.

Never redesign UI.

Never remove components.

Never rename routes.

Never change folder structure.

Only replace the data layer.

Use existing Axios client.

Never create another Axios client.

Never use localStorage.

PostgreSQL is the source of truth.

Always preserve validations.

Always preserve dialogs.

Always preserve tables.

Reuse existing components.

Never modify unrelated modules.

Every feature must compile.

Every Pull Request should modify only one module.
